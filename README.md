# dndSteno

Стенограф для D&D: записывает партию, расшифровывает её в текст, а дальше
(в планах) делает краткое саммари и заметки в Obsidian.

## Как устроено

Программа — это цепочка независимых шагов. Каждый читает и пишет файлы в папке
сессии, поэтому любой шаг можно перезапустить, не переигрывая партию:

```
sessions/2026-10-23/
  audio/part_001.flac, part_002.flac, ...   ← steno record
  transcript/part_001.json, ...             ← кэш по кускам
  transcript.md, transcript.json            ← steno transcribe
```

| Шаг | Статус |
|---|---|
| Запись на диск кусками (FLAC 16 кГц моно) | готово |
| Расшифровка (faster-whisper, русский, словарь имён) | готово |
| Кто говорит (раздельные дорожки / диаризация) | планируется |
| Саммари через локальную нейросеть (LM Studio) | готово |
| Заметка о сессии и дополнение статей в Obsidian | готово |
| Окно программы (запись, сессии, настройки) | готово |

## Установка

Нужен Python 3.11+.

```bash
py -3.12 -m venv .venv
.venv\Scripts\pip install -e ".[dev]"
```

При первой расшифровке скачается модель Whisper (`large-v3-turbo` — около 1.6 ГБ).

## Окно программы

Двойной щелчок по **`dndSteno.cmd`** в папке проекта (можно сделать ярлык на рабочий стол).

- **Запись** — выбор микрофона, кнопка записи, индикатор уровня. При речи полоска должна
  заходить за пунктир; если долго тихо — программа предупредит.
- **Сессии** — список партий, кнопка «Расшифровать», текст расшифровки, аудиокуски,
  импорт готовых записей (с телефона, из Discord/Craig).
- **Настройки** — всё из `dndsteno.toml`; сохраняются в этот файл.

Долгие задачи (запись, расшифровка) идут в фоне — их видно внизу окна, там же кнопка отмены.
Если что-то пошло не так, подробности в `dndsteno.log`.

## Саммари и Obsidian

1. В LM Studio загрузите модель и запустите сервер (Developer → Start Server, адрес
   `http://127.0.0.1:1234`). Для RTX 4070 (12 ГБ) подойдёт модель класса Qwen3 14B или gpt-oss-20b.
2. В «Настройки → Obsidian» укажите папку vault и папку кампании (например «Большой куш»).
3. Сессия → вкладка **«Саммари»** → «Сделать саммари». Нейросеть читает расшифровку по кускам,
   собирает итог и сверяет найденные факты с вашими статьями, чтобы не повторять уже записанное.
4. Вкладка **«Obsidian»**: список изменений с галочками и предпросмотр. Отметьте нужное и нажмите
   «Записать отмеченное в Obsidian».

Что попадает в vault:
- **Заметка о сессии** в `<кампания>/Сессии/Сессия <дата>.md`: кратко, ход по сценам с
  временем, открытые вопросы, ссылки. Если в игре прозвучала дата в формате ГГГГ-ММ-ДД —
  ставится `fc-date`, и сессия появляется в Calendarium.
- **Дополнения статей** — помеченный блок в конце существующей статьи:
  ```
  > [!ai] 🤖 Нейросеть · Сессия 2026-10-23
  > - Пригласил [[Бадб + Эйлет]] на ужин `01:12:05`
  ```
- **Новые статьи** (NPC, места, которых ещё нет) — в `<кампания>/Новое от нейросети/`,
  тоже с пометкой. Разложите их по папкам сами.

Гарантии: существующий текст статей никогда не меняется и не удаляется — программа только
дописывает в конец и проверяет, что прежний текст сохранился байт-в-байт; файлы не
перезаписываются; повторная запись той же сессии ничего не дублирует; копия каждой статьи до
правки лежит в `sessions/<дата>/obsidian_backup/`.

## Командная строка

То же самое без окна:

```bash
.venv\Scripts\steno devices          # какие есть микрофоны
.venv\Scripts\steno record           # запись; Enter или Ctrl+C — стоп
.venv\Scripts\steno transcribe       # расшифровать последнюю сессию
.venv\Scripts\steno summarize        # саммари через LM Studio
.venv\Scripts\steno obsidian         # показать изменения для vault; --apply — записать
```

- `steno record --session 2026-10-23` — продолжить запись в ту же сессию
  (после перерыва появится `part_00N+1`).
- `steno transcribe 2026-10-23` — конкретная сессия;
  `steno transcribe путь\к\файлу.mp3` — любой аудиофайл (результат ляжет рядом).
- Расшифровка кэшируется по кускам: если прервать, следующий запуск продолжит с
  того же места. `--force` — расшифровать заново.

### Словарь имён

Whisper плохо угадывает фэнтезийные имена. Перечислите персонажей, NPC и
локации в «Настройки → Словарь имён» (или `glossary` / `glossary_file` в
`dndsteno.toml`), и он будет писать их правильно.
